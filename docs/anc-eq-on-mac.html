How to change the equalizer and noise cancelling on OPPO, OnePlus or realme earbuds from a Mac

Short answer: macOS has no control for it, and nothing in System Settings is hiding one. The settings live on the earbuds and travel over a separate Bluetooth channel that Apple's software never opens. An app that opens that channel can change them, and on a Mac that means installing one.

First, why there is no setting to find

It is easy to spend an hour in the Bluetooth pane looking for a noise-control switch that is not there. It is not there because of how the earbuds talk.

When you pair these earbuds, macOS sets up an audio link — the part that plays sound. The settings are somewhere else: the earbuds also advertise a separate vendor control service, and everything configurable travels across that. Battery, wear state, which mode the cancellation is in, the equalizer preset, the touch gestures, the firmware string, the multi-connect list. macOS supports audio, input devices and a little battery reporting, and it does not open vendor control services, so there is no Apple-side control to expose and never will be.

This is also why the phone app is not replaceable by a Mac preference pane: it is not an audio setting, it is a device conversation.

What macOS does give you

  • Pairing and connection. System Settings → Bluetooth. The earbuds play audio on the Mac fine, with no extra software at all.
  • Microphone and output selection. The Sound pane and per-app output selection.
  • Codec visibility — for some devices, not all, and not with any useful control over which codec is chosen.
  • Battery — for some third-party earbuds macOS shows nothing, or one merged figure covering both buds.

That is the whole list. Nothing above changes a setting on the earbuds.

The two-minute version that works

  1. Pair the earbuds with the Mac once in System Settings → Bluetooth. If they are already paired from a phone-only setup, they may need putting into pairing mode again.
  2. Install BudsDesk from GitHub Releases and open it. macOS asks for Bluetooth access the first time; the permission is tied to the app, so it survives updates.
  3. Change the mode or the preset in the window, or straight from the menu-bar item if you only want the noise mode.
  4. Watch what it settles on. The app writes the setting and then reads the value back off the earbuds. If the earbuds decline, the control returns to what they actually hold — which is the honest behaviour, and the reason a stuck setting never looks applied when it is not.

The settings are stored on the earbuds. Change the equalizer from the Mac and the phone app will show the same value, and vice versa. BudsDesk keeps no settings of its own.

Does the equalizer on the earbuds beat an equalizer on the Mac?

They are different things and both are legitimate.

  • On-device (the earbuds' own presets and BassWave) applies to whatever source is playing — the Mac, the phone, a TV. It is stored in the earbuds, and it is what the phone app's equalizer screen changes.
  • On the Mac (Audio MIDI Setup, or a player's own equalizer) shapes only the audio the Mac is playing. It disappears when you switch source.

So a Mac-side equalizer cannot substitute for the earbuds' own curve, and a preset on the earbuds does not replace per-app shaping on the Mac. If you want the sound changed everywhere, it has to be changed on the earbuds.

If it does not connect

  • The earbuds are asleep in the case, or out of range. This is the most common one by a distance. BudsDesk will say exactly that rather than showing stale values.
  • Another device is holding them. These earbuds accept one active source; if the phone is playing, the Mac may be refused or will take over. Some models allow two connected devices — the app lists what the earbuds report as linked.
  • Bluetooth permission was declined. macOS returns an empty device list rather than an error when a process lacks Bluetooth access, which looks identical to "no earbuds paired". Check System Settings → Privacy & Security → Bluetooth.
  • The model is not catalogued. It will still connect and read, but nothing will be writable until that model has been recorded. See models.

Questions

Why can't macOS change the noise cancelling?
Because the setting does not travel over the audio connection. It goes over a separate vendor control service that Apple's Bluetooth stack does not open.
Can I use an Android emulator to run the phone app instead?
We have not tested specific emulators, and we will not claim none can pass a real Bluetooth radio into a guest system. What is certain is that these settings travel over a Bluetooth channel, so an app running without a real radio has nothing to talk to.
Will the changes survive a reconnect?
Yes — they are stored on the earbuds. Re-pairing the earbuds does not reset them.
Which models does this work with?
OnePlus Buds 4 is measured end to end. Other OPPO, OnePlus and realme models that advertise the same control service connect and read; they have no write path until someone records them.
